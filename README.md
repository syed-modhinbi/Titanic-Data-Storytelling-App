# Titanic Data Storytelling App

## Overview
This project presents a data storytelling analysis of the Titanic dataset. The goal is to identify patterns and factors that influenced passenger survival using data visualization and exploratory data analysis techniques.

## Features
- Dataset Introduction
- Exploratory Data Analysis (EDA)
- 5 Visualizations
- Insights and Findings
- Final Conclusion

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
Titanic Dataset
